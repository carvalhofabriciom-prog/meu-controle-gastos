MEU CONTROLE DE GASTOS — V3 SENHA + PWA

Senha configurada: 151957

Esta versão NÃO usa cadastro/e-mail/Supabase.
Os dados ficam salvos localmente no navegador/dispositivo (localStorage).
A senha é verificada por hash no código, mas esta proteção é para privacidade/uso pessoal, NÃO é segurança de nível bancário: alguém com conhecimento técnico e acesso aos arquivos pode alterar o código.

PARA INSTALAR NO CELULAR:
1. Publique esta pasta em uma hospedagem HTTPS.
2. Abra o endereço no celular.
3. No Android/Chrome, use "Instalar app" quando aparecer ou o menu do navegador.
4. No iPhone/Safari, use Compartilhar > Adicionar à Tela de Início.

IMPORTANTE:
- Abrir index.html com duplo clique (file://) NÃO instala como PWA.
- Para instalação PWA, o site precisa estar em HTTPS (ou localhost para testes).
- O manifest já tem ícones 192x192 e 512x512 e display standalone.
- Depois de instalado, o app abre como aplicativo.

DADOS:
- Sem nuvem nesta versão.
- Os gastos ficam no navegador onde forem cadastrados.
- Se limpar os dados do navegador, os dados locais podem ser apagados.
